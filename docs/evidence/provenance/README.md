# Simulation policy provenance amendments

These are sanitized provenance amendments for read-only evidence. No new measurement was made. The original records are preserved unchanged at the source commit and in private hash-addressed storage. The [amendment manifest](provenance-amendments.json) records original and publication hashes, sizes and metadata JSON pointers.

All numeric measurement tokens, outcomes, scores, fingerprints and simulation labels remain unchanged. Identifying string metadata is withheld or normalized. These publication files are not operator authorization, training, checkpoint or dataset inputs. Use the original verified private artifacts for execution.

JSONL metadata pointers use a zero-based `/record-N/` prefix. The manifest also preserves the earlier main timeline hash and its exact-prefix relationship to the source timeline. Original operator records remain local and ignored, including the append-only timeline output. They are not redirected to these read-only exports.
