## Ambiguities and Retained Material

- Exact Synria upstream commit and Yahboom archive checksum are absent from the
  integration map. The setup script requires an explicit source identifier and
  records file hashes; it does not claim a newly obtained source reproduces an old run.
- `isaac/usd/robots/synria_6dof_arm/payloads/Physics/{mujoco,physics,physx}.usda`
  and `payloads/robot.usda` describe the older approximate `joint_1` /
  `shoulder_link` model, despite the surrounding vendor-labelled folder and
  some Alicia metadata. Retained as first-party approximation output. They are
  not a valid replacement for the removed vendor model.
- Both `rosmaster_m3pro.urdf` copies and both `rosmaster_m3pro/` USD trees
  contain the older first-party primitive model, not the vendor M3Pro geometry.
  The Yahboom metadata incorrectly calls its URDF vendor-originated. Retained.
- `source_urdf/` xacros, current ROS xacro wrappers, v2 pad/repaired/nogripper/
  gripper-reference layers and scene layers contain first-party definitions or
  external references, not embedded vendor mesh data. Retained. References will
  be unresolved until local inputs are obtained and converted.
- The first-party mirrored scene layers reference an external Alicia-D-ROS2
  checkout. Its game-table assets are not in this repository; no exact source
  revision is recorded. Request the referenced scenes from Synria if absent.
- Robotiq geometry origin is identifiable, but its precise upstream revision and
  redistribution terms are not established here. Removed; no license inferred.
- Bundled NVIDIA `.claude/skills/` material is separately attributed in NOTICE,
  retained under Task B's instruction, and is not covered by the root MIT grant.
- Reports and media remain as explicitly requested. They may depict the vendor
  robots; removal of source geometry is not a claim that every report is free of
  third-party depictions.

## Breakage and Setup

Without local vendor assets, Yahboom display/MoveIt launches, Synria ROS xacro
expansion, vendor description integration tests, USD import, and robot-dependent
Isaac tasks cannot run. Pure Python utilities and first-party static checks remain
available. Asset-dependent tests explicitly skip missing optional inputs; partial
installs still fail validation.

Run `python3 scripts/fetch_vendor_assets.py --help` for source locations and
commands. Obtain the Synria description checkout and Yahboom workspace from their
vendors under their terms. The script stages only required assets, records hashes,
normalizes mesh paths, and preserves local Synria dynamics. Then run the retained
Isaac Sim 5.1 importer into the ignored v2 configuration directory. Existing
first-party v2 patch layers stay in place. CAD and Robotiq diagnostics need separate
vendor/NVIDIA downloads. Their complete historical regeneration is not established.
