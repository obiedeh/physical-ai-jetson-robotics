run inside Isaac Sim's Python on the Linux RTX 5090 workstation. The scripts

### V1 task phases

```
PICK_FROM_BOARD → PLACE_ON_ZONE → PICK_FROM_ZONE → RETURN_TO_BOARD → SUCCESS
```

Each phase transition is driven by per-env reward signals; the
`TrialStateManager` tracks phase, consecutive-grasp counter, and step
counts for all 4 096 parallel environments on the CPU.

## GR00T N1.7 Fine-Tune

Post-trains **NVIDIA Isaac GR00T N1.7** on Synria pick-and-place
demonstrations. Follows NVIDIA's published
[LeRobot SO-101 post-training recipe](https://huggingface.co/blog/nvidia/gr00t-n1-5-so101-tuning)
with Synria-specific embodiment values (joint names, action dim, cameras).

The Synria 6DOF arm is structurally the same class of robot as the SO-101
(6 revolute joints + parallel-jaw gripper + wrist camera), so the recipe
carries over with embodiment-name changes. Fine-tuning a foundation model
converges with far less data than PPO-from-scratch and produces a stronger
portfolio signal.

### Embodiment

| Parameter | Value |
|---|---|
| `embodiment_tag` | `synria_6dof_v0` |
| Arm joints | `Joint1` … `Joint6` (from SolidWorks-export URDF) |
| Gripper joints | `left_finger`, `right_finger` (prismatic, ±0.025 m) |
| Action dim | **8** — 6 arm position targets + 2 finger position targets |
| Cameras | `wrist_c10` (C10 wrist), `overhead_board` (scene overhead) |
| Image size | 224 × 224 (GR00T standard) |

### Two integration paths

**Path A — direct fine-tune**
Collect ~100 Synria demonstrations per game (teleop or scripted), then
fine-tune GR00T N1.7 on them directly. Lower data volume, higher demo
quality requirement.

**Path C — GR00T-Mimic amplification**
Amplify a small seed set (~100 demos) into 100K+ synthetic trajectories
using NVIDIA Cosmos / GR00T-Mimic, then fine-tune on the amplified set.
NVIDIA reports ~780K trajectories in ~11 hours on H100 with a ~40%
downstream performance lift.

The two combine cleanly: collect seed → amplify → fine-tune → evaluate.

### Pipeline overview

```
1. embodiment.py  — register Synria embodiment tag + modality config
2. dataset.py     — point at seed or Mimic-amplified demo paths
3. finetune.py    — wrap launch_finetune.py with Synria defaults
4. inference.py   — roll out inside the Isaac Lab task, capture success rate
```

### Demo paths (on disk)

```text
reports/training/synria_chess_lerobot_demos/      ← seed demos (collect)
reports/training/synria_chess_mimic_amplified/    ← Mimic output (optional)
runs/gr00t_synria_chess_v0/                       ← checkpoint (gitignored)
reports/training/gr00t_synria_chess_eval.json     ← per-episode eval metrics
```

Same structure for `ludo` and `checkers`.

### RTX 5090 workflow

```bash
# 1. Install GR00T (Python 3.10 strict — separate uv venv recommended)
git clone https://github.com/NVIDIA/Isaac-GR00T ~/code/Isaac-GR00T
cd ~/code/Isaac-GR00T && uv sync

# 2. Collect ~100 seed demos per game (LeRobot format)
#    Teleop with a leader arm, or scripted from the Isaac Lab task.

# 3. (Optional) Amplify with GR00T-Mimic
#    gr00t-mimic amplify --input ... --output ... --target-trajectories 100000

# 4. Fine-tune
python -m isaac.isaaclab_tasks.synria_pickplace.gr00t.finetune \
    --game chess \
    --amplified \
    --base-model nvidia/GR00T-N1.7-3B \
    --output-dir runs/gr00t_synria_chess_v0 \
    --gr00t-repo ~/code/Isaac-GR00T \
    --num-epochs 10 --batch-size 16 \
    -- --lora-rank 16

# 5. Evaluate inside Isaac Lab
python -m isaac.isaaclab_tasks.synria_pickplace.gr00t.inference \
    --task Synria-Chess-PickPlace-v0 \
    --checkpoint runs/gr00t_synria_chess_v0 \
    --num-episodes 20 \
    --report reports/training/gr00t_synria_chess_eval.json
```

### Platform notes

Isaac Sim 5.1.0 crashes on RTX 5090 (Blackwell, sm_120) — its CUDA 12.0
stack has no compiled shaders for that architecture. Isaac Sim 5.1
(Kit 110.0.0, CUDA 12.8/13.x driver) resolves this.

The gfxstream Vulkan ICD presents a duplicate GPU and is excluded via
`VK_ICD_FILENAMES` in render/launch scripts. Pin Vulkan to the NVIDIA ICD
directly.
