# Synria + Chess Tabletop Training Scene

Training scene for the Synria 6DOF arm playing chess: arm mounted on a table with a standard 8 × 8 chess board and 32 pieces in the opening position staged within reach.

## Layout

- Floor, table (1.20 × 0.80 × 0.75 m), Synria arm — shared scaffolding via `isaac/scripts/_synria_scene_common.py`
- Chess board: 8 × 8 squares, 0.045 m per square (0.36 m playing area), 0.02 m border → 0.40 m total board, centered at (x = 0.10, y = 0) on the table top
- 32 pieces in the standard opening position
  - White on ranks 1 (back rank) and 2 (pawns)
  - Black on ranks 7 (pawns) and 8 (back rank)
  - 6 piece types with distinct composite-primitive shapes (see below)
- **Four staging zones** (board ↔ staging pick-and-place targets, one per side of the board):
  - `left` (blue, −Y of board), `right` (orange, +Y), `top` (purple, −X toward arm), `bottom` (green, +X toward operator)
  - See [docs/SYNRIA_PICK_AND_PLACE_TASK.md](../../../../docs/SYNRIA_PICK_AND_PLACE_TASK.md) for the task spec
- Overhead RGB camera (board-state view) + operator perspective camera

Units: meters, kilograms, Z-up.

## Training task

Primary task: pick a piece off the board, place it on one of the four staging zones, return it to its original square. Full spec in [docs/SYNRIA_PICK_AND_PLACE_TASK.md](../../../../docs/SYNRIA_PICK_AND_PLACE_TASK.md).

Initial state for this scene:
- 32 pieces in standard chess opening (white ranks 1–2, black ranks 7–8)
- All four staging zones empty

## Piece shape placeholders

These are visually distinguishable composite primitives, not chess-piece meshes. Final visual fidelity is a follow-up.

| Type | Shape |
|---|---|
| Pawn | cylinder base + small sphere on top |
| Rook | cylinder base + cube on top (battlements proxy) |
| Knight | cylinder base + rectangular box on top |
| Bishop | cylinder base + cone + small sphere tip |
| Queen | cylinder base + large sphere + small spike cylinder |
| King | cylinder base + large sphere + cross (vertical box + horizontal box) |

Pieces use side-color (white / black) — distinguishing piece type from color is done by shape.

## Build

The scene is generated by [`isaac/scripts/build_synria_chess_scene.py`](../../scripts/build_synria_chess_scene.py).

On the Linux RTX 5090 workstation:

```bash
bash scripts/linux_rtx/build_synria_chess_scene.sh
```

The script writes `synria_chess_v0.usda` to this folder. Commit the result after a successful build.

## Validation checklist (run once on RTX)

- [ ] Script completes without errors under Isaac Sim 5.1
- [ ] Open the resulting USD in Isaac Sim — stage loads, no missing-prim warnings
- [ ] Synria arm reference resolves and the arm appears mounted on the table top
- [ ] Confirm arm reach: every square on ranks 1, 2, 7, 8 is within 0.65 m of the arm base
- [ ] Confirm piece-pickup clearance: gripper open width fits 0.024 m piece diameter
- [ ] Each of the 6 piece types is visually distinguishable from overhead camera
- [ ] Overhead camera frames the full board with margin
- [ ] Physics scene present, pieces respond to gravity (test by tipping one)
- [ ] No prim collisions between arm rest pose and the back-rank pieces

## Known limitations (intentional, refine on RTX)

- Pieces are composite primitives, not vendor meshes. Swap for real chess-piece USD assets in v1.
- Materials are flat display colors; no PBR or wood-grain board texture.
- Square coordinate labels (file a-h, rank 1-8) are encoded in prim names (`sq_e4`, etc.) but not displayed visually on the board edges.
- The 50-move clock, captured-piece staging area, and any sound assets are not modeled.
