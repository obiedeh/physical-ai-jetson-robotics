# Synria + Ludo Tabletop Training Scene

The first training scene for the Synria 6DOF arm: arm mounted on a table with a Ludo game board, tokens, and die staged in front of it.

This is the scene that the Synria arm trains against on the RTX 5090 workstation before sim-to-real deployment to Jetson AGX Thor.

## Layout

- Floor plane at z = 0
- Table: 1.20 × 0.80 × 0.04 m top, 0.75 m height
- Synria arm: mounted on the table top at x = −0.50 m (near edge), within 0.65 m reach of the board
- Ludo board: 0.40 × 0.40 m, centered at (x = 0.10, y = 0) on the table top
  - Four colored home quadrants: red, blue, green, yellow
- 16 Ludo tokens (4 per color), staged in the four home corners
- One die placed beside the board
- **Four staging zones** (board ↔ staging pick-and-place targets, one per side of the board):
  - `left` (blue, −Y of board), `right` (orange, +Y), `top` (purple, −X toward arm), `bottom` (green, +X toward operator)
  - See [docs/SYNRIA_PICK_AND_PLACE_TASK.md](../../../../docs/SYNRIA_PICK_AND_PLACE_TASK.md) for the task spec
- Overhead RGB camera (board-state view)
- Operator-perspective RGB camera (review/recording view)
- Distant + dome lighting

Units: meters, kilograms, Z-up.

## Training task

Primary task: pick a token or the die off the board, place it on one of the four staging zones, return it to its original square. Full spec in [docs/SYNRIA_PICK_AND_PLACE_TASK.md](../../../../docs/SYNRIA_PICK_AND_PLACE_TASK.md).

Initial state for this scene:
- 16 tokens in their home quadrants (4 per color)
- 1 die adjacent to the board
- All four staging zones empty

## Build

The scene is generated by [`isaac/scripts/build_synria_ludo_scene.py`](../../scripts/build_synria_ludo_scene.py) (the source of truth — edit there, not here).

On the Linux RTX 5090 workstation:

```bash
bash scripts/linux_rtx/build_synria_ludo_scene.sh
```

Or with Isaac Sim's Python directly:

```bash
~/.venv/isaacsim5/bin/python isaac/scripts/build_synria_ludo_scene.py
```

The script writes `synria_ludo_v0.usda` to this folder. Commit the result after a successful build.

## Validation checklist (run once on RTX)

- [ ] Script completes without errors under Isaac Sim 5.1
- [ ] Open the resulting USD in Isaac Sim — stage loads, no missing prim warnings
- [ ] Synria arm reference resolves and the arm appears mounted on the table top
- [ ] Confirm arm reach: the far edge of the Ludo board is within 0.65 m of the arm base
- [ ] Confirm token-pickup clearance: gripper open width fits a 0.024 m token diameter
- [ ] Overhead camera frames the full board with margin
- [ ] Physics scene present, tokens and die respond to gravity
- [ ] No prim collisions between arm rest pose and table top

## Known limitations (intentional, fix on RTX)

- Token geometry is a placeholder cylinder. Final tokens may need vendor or printable mesh assets.
- The Ludo "track" (52 squares + home cross) is not yet drawn — only the four colored home quadrants are present. Add the track as a texture or as inset prims once the base scene validates.
- Materials are flat display colors. Add PBR materials and a board texture during the visual polish pass.
- The die has six identical faces. Add pip textures or use a vendor die mesh later.
- Arm rest pose, gripper alignment to the board surface, and token-pickup approach poses are not configured — those belong to the Isaac Lab task config (separate follow-up).
