# Isaac Robot Assets

Vendor geometry and derived robot payloads were removed on 2026-09-07.
[Manifest](../../../docs/VENDOR_ASSET_REMOVAL.md) and
[local setup](../../../docs/VENDOR_INTEGRATION_MAP.md) describe the boundary.

Retained: first-party approximate models, source xacros, conversion tools,
metadata, reference-only v2 patch layers and documentation. A reference layer
can be present while its required vendor payload is absent.

The current Synria v2 root references locally generated configuration files.
Older approximate Synria physics layers and primitive Yahboom conversions are
historical first-party outputs, not current vendor geometry or physical validation.
